# 全业务柔性调度强化学习 v5

`PortEnergyDispatchEnv-v5` 是在 v1–v4 历史环境、模型、报告与失败候选均不改写的前提下新增的离线候选合同。它只把适合连续资源分配的决策交给强化学习；具名泊位、箱位、任务、监管放行、碳核算、结算、联锁和生产批准仍由确定性流程或外部权威系统负责。

## 观测

环境共有 73 个归一化观测：v4 的 48 项能碳、作业、实港适配和监管韧性状态，加上 25 项柔性业务状态：

- 自动导引车车队可用率、平均荷电状态、充电需求、离场刚性电量与充电桩可用率；
- 冷藏箱连接数量、基准负荷、温度安全裕度和累计热债；
- 楼宇关键负荷与可移峰负荷；
- 岸电已预约功率与窗口剩余时间；
- 设备健康、岸桥/场桥故障风险和维护窗口；
- 需求响应事件、目标、剩余时间与当前交付状态；
- 可再生能源因果预测、累计自动导引车缺电、冷藏箱违规、需求响应欠交和柔性动作投影量。

观测不包含未来测试行；监管机关的检查、扣留和放行只作为外生事件进入，不允许策略生成这些事件。

## 动作

连续策略输出 10 个归一化动作：岸电、岸桥资源、堆场资源、储能、检查准备、放行后恢复、自动导引车充电、冷藏箱服务、楼宇柔性负荷、需求响应承诺。DQN 使用 243 个经过业务耦合筛选的显式动作模板，避免 10 维三档全笛卡尔积产生 59,049 个稀疏动作。

以下内容不属于强化学习动作：

- 具名船舶准时到港、泊位分配、岸桥任务、堆场箱位、外集卡预约：由联合运筹优化生成建议并经人审批；
- 海事/海关检查、扣留与放行：仅接受主管机关权威事件；
- 配电潮流、保护、孤岛与 N-1：由物理模型和保护规则判断；
- 排放清单、节能量测量与验证、账单/需求响应/绿证结算、碳资产：由可审计确定性账本处理；
- 替代燃料和绿色航运走廊：由港航协同、安全许可、风险评估、应急演练和服务回执流程处理；
- 可编程逻辑控制器联锁、设备能力检查、最终批准、人工接管和回滚：在应用进程外执行。

机器可读责任矩阵由 `GET /api/rl/business-coverage` 返回。

## 奖励与硬约束

奖励权重为：碳 0.15、岸电 0.06、成本 0.15、延误 0.12、安全 0.18、峰值 0.08、储能终值 0.05、自动导引车服务 0.06、冷藏箱安全 0.07、需求响应交付 0.05、设备健康 0.03。吞吐和监管恢复服务另有归一化正向项。

安全不能靠奖励权衡。环境在动作执行前强制：

1. 电网容量与储能荷电状态/终值可达性；
2. 自动导引车离场刚性电量；
3. 冷藏箱最低服务、低温度裕度和热债上限；
4. 楼宇关键负荷不参与削减；
5. 电网受限时依次削减非关键楼宇、非刚性自动导引车、可延后冷藏箱，再削减岸电并回补船舶辅助燃油账本；
6. 监管权力始终外生、物理下发始终关闭。

## 数据与可替换合同

`port_la_2020_2024_operational_flex_hourly` 有 43,848 个连续小时。洛杉矶港逐日船舶记录、月度吞吐量和 EIA/EPA 电网数据是公开锚点；自动导引车、冷藏箱、楼宇、需求响应、设备健康、维护、监管和预约字段是可复现工程情景，不是设备遥测。所有补足字段都在 metadata 的 `field_provenance.modeled_supplement_columns` 中单列，`independent_field_measurement_columns` 为空。

未来现场包使用 `scripts/prepare_port_dataset.py --environment-id PortEnergyDispatchEnv-v5 --column-map ... --environment-config ... --site-training-evidence ...` 进行一一映射。`GET /api/rl/datasets/{id}/replacement-readiness` 只有在以下证据同时成立时才允许进入现场重训练和影子评测：八类源系统全部到齐且签名验证、6 个核心业务/能价字段和 44 个 v5 运营字段均独立计量或来自批准的可追溯现场派生、38 个环境参数全部声明并标定、完整事件血缘、至少 180 天/四季/七类异常覆盖、100% 电表覆盖、能量平衡误差不高于 2%、账单对账误差不高于 1%、运行方和独立方签字。通过该门禁仍不授予物理控制权。

## 训练和冠军门禁

PPO、SAC、TD3、DQN 都调用真实 Stable-Baselines3 `learn()`。训练只读 train，参数和算法选择只读 validation；首次 test 只用于最终业务价值报告。每个算法保留两个候选和三个最终随机种子，全部模型、哈希、评测和失败门禁永久留档。

RL 必须相对四步约束 MPC 同时满足三随机种子：零安全违规、成本和碳排不退化且配对 95% 区间下界不低于零、岸电使用/峰值/吞吐不退化、延误不增加、自动导引车离场和冷藏箱热安全零违规、相对外生事件/强基线的需求响应承诺不低于 98%、已承诺容量交付不低于 98%、奖励提高。承诺率和交付率分开计算，禁止用“少承诺”制造 100% 交付率。支配投影先尝试完整 RL 动作，再按 75%/50%/25%/10%/5%/2% 沿学习方向收缩；每一步都先检查需求响应承诺和交付，仍不合格就回退 MPC。只有实际执行后的单步安全与业务指标支配 MPC 才接受；三个种子的平均学习贡献都必须至少为 1%，且贡献按十维执行动作相对 MPC 的归一化平均绝对偏差计量，避免把纯 MPC 冒充 RL 冠军。通过者仍只标记为离线冠军，`production_eligible=false`。
