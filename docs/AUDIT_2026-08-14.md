# 2026-08-14 top-tier open-source audit

This file freezes the read-only baseline observed before v0.4.0 changes and records the
incremental resolution. It does not replace `reports/offline_benchmark_v3.json`,
`reports/offline_benchmark_vessel_activity_v1.json`, `reports/port_landing_benchmark_v4.json`,
or the blocked TD3 evidence.

Baseline reproduced before modification:

- Git: clean `main`, aligned with the previously published `57958f6` baseline.
- Backend: 51 tests passed in 87.81 seconds.
- Structure validation, Ruff, `pip check`, and Vite production build passed.
- Existing strengths: PPO/SAC/TD3/DQN plus constrained MPC, no-render training, chronological
  train/validation/test isolation, test-only replay, model/data hashes, path-safe dataset registry,
  API role gates, request limits, audit chaining, CI, CodeQL, Scorecard, and explicit production
  disablement.

## Production boundary that remains intentionally blocked

The completed work is an end-to-end simulation and evidence system, not a production control
system. Production remains blocked until approved TOS, EMS, BMS, BA, meter/PLC, shore-power,
weather and identity adapters; site topology; field calibration; shadow operation; rollback drills;
two-person identity proof; human acceptance; and independent electrical/PLC interlocks all exist.
