# 港口排放源清单与核证边界

`port-emissions-inventory.v1` 是在原有轨迹碳核算旁新增的完整港口排放源合同。
它不改写历史指标，也不会把缺少现场活动数据的源类记为零排放。

## 源类覆盖

清单固定覆盖七类港口相关排放源：

1. 远洋船舶靠泊辅机；
2. 港作船与拖轮；
3. 港口装卸设备；
4. 外集卡与重型车辆；
5. 港区铁路机车；
6. 外购电力；
7. 固定燃烧源与备用发电。

每类源分别记录活动数据状态、港口活动边界、温室气体范围、历史口径、
二氧化碳当量、八类温室气体或空气污染物字段、排放因子编号、证据类型、
保证状态和缺失证据。污染物字段包括二氧化碳、甲烷、氧化亚氮、氮氧化物、
硫氧化物、可吸入颗粒物、细颗粒物和黑碳。

## 当前公开基准的真实覆盖

当前公开数据只能形成两个未核证的情景结果：

- 外购电力：公共电网小时碳强度与模拟终端负荷，作为范围二所在地法情景；
- 远洋船舶靠泊辅机：由岸电缺口推导的辅助燃料情景。

船舶所有权和运营控制证据尚未接入，因此新增清单不会直接把靠泊船舶排放
归入企业范围一或范围三。原驾驶舱的“范围一辅助燃油”作为历史情景口径保留，
但不能用于企业温室气体清单或监管报送。

其余五类源、范围二市场法以及全部污染物明细保持 `unavailable`。当前清单的
`assurance.status=blocked`、`regulatory_submission_allowed=false`。

## 核证所需证据

要解除核证门禁，必须至少提供：

- 具名报告主体、组织边界以及股权比例法或运营控制法；
- 船舶、港作船、设备、车辆、铁路和固定燃烧源资产或活动台账；
- 收入电表、燃料票据、设备分表与账单对账记录；
- 发动机、燃料、负荷、排放控制技术和污染物排放因子；
- 供应商特定排放因子、购电协议或其他市场法凭证；
- 基准年重算、数据修订、质量控制、不确定度和独立核证程序。

## 接口

```text
GET /api/dashboard/carbon-inventory
```

同一对象也包含在 `GET /api/dashboard/snapshot` 的 `carbon_inventory` 字段中。
`evidence_sha256` 是对清单其他全部字段的规范 JSON 计算得到的 SHA-256，便于
下游保存和核对证据版本。

该合同参考国际海事组织港口排放清单的源类范围，并为 ISO 14064-1 与
ISO 50001 所需证据预留字段；这表示数据合同映射，不表示认证、核证或监管认可。
