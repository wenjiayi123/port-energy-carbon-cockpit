# v0.2.0 — Auditable benchmark foundation / 可审计基准底座

This private-review release packages the Port Energy & Carbon RL Cockpit as a compact, reproducible open-source repository. It does not claim a live terminal connection or production dispatch authority.

本次私有审阅版本将港口能碳强化学习驾驶舱整理为紧凑、可复现的开源仓库；项目不宣称已连接真实码头生产系统，也不具备生产调度权限。

## Highlights / 核心能力

- Four executable RL baselines—PPO, SAC, TD3, and DQN—plus a constrained MPC control baseline.
- Training runs without rendering; trajectory generation is restricted to held-out evaluation.
- Dataset fingerprints, immutable run manifests, artifact hashes, evaluation evidence, and audit events.
- A bilingual React cockpit backed by FastAPI health, readiness, metrics, governance, and role-gated mutation routes.
- Public benchmark data with explicit source, units, assumptions, split evidence, and carbon-accounting boundaries.
- Pinned CI actions, dependency audits, CodeQL/Scorecard public-release gates, Dependabot grouping, and hardened containers.

- 四种可执行强化学习基线：PPO、SAC、TD3、DQN，以及受约束的 MPC 控制基线。
- 训练阶段不渲染；轨迹仅在留出测试集评估阶段生成。
- 数据指纹、不可变运行清单、模型哈希、评估证据与审计事件形成可追溯证据链。
- React 双语驾驶舱连接 FastAPI 健康检查、就绪检查、指标、治理与分角色变更接口。
- 公共基准数据明确记录来源、单位、假设、切分证据和碳核算边界。
- 固定版本 CI、依赖审计、公开阶段 CodeQL/Scorecard 门禁、Dependabot 分组与容器加固。

## Trust boundary / 可信边界

The bundled dataset is an offline public benchmark. Production dispatch remains disabled unless separately verified adapters, credentials, operational controls, and acceptance evidence are supplied.

内置数据集属于离线公共基准。只有在另行提供并验证数据适配器、凭证、运行控制与验收证据后，生产调度才可能启用。
