# Repository contents

This repository includes the source code, public-data attribution, reproducible
offline benchmarks, automated tests, security policy, contribution guide, model
and data cards, and deployment examples for the energy-carbon cockpit.

Generated runs, model binaries, private datasets, submission material, local
credentials, and workstation-specific files are intentionally excluded. The MIT
software license does not replace the original terms of third-party datasets or
assets.
