# 港口配电数字孪生与韧性评估

本模块把原有“电网进口功率 + 变压器容量裕度 + 储能状态”扩展为可复算、可验签、失败关闭的港口配电工程筛查合同。它覆盖单线拓扑、母线与馈线、开关状态、电压与无功、谐波、变压器热老化、N-1、孤岛、充电排队及储能质保。

它不是继电保护整定、短路计算、弧闪分析或现场倒闸系统。即使 14 项门禁全部通过，输出仍为人工复核和影子运行建议：

```json
{
  "advisory_only": true,
  "switching_command_allowed": false,
  "protection_setting_change_allowed": false,
  "islanding_command_allowed": false,
  "equipment_dispatch_allowed": false,
  "production_authority": false
}
```

## 1. 版本化合同

- 输入：`port-electrical-network-input.v1`
- 输出：`port-electrical-network-assessment.v1`
- 当前计算方法：`radial_lindistflow_thermal_erlang_c_v1`
- 输入回执：完整输入的规范化 JSON SHA-256
- 输出回执：除自身哈希字段外完整报告的规范化 JSON SHA-256

输入使用具名资产标识，不接受仅有“总负荷”“总容量”的聚合值替代设备级证据。

## 2. 六个独立证据域

| 源域 | 必须提供的现场证据 | 建议系统所有者 |
| --- | --- | --- |
| `single_line_topology` | 母线、线路、变压器、并网支路、电源、N-1 和孤岛场景 | 电气资产管理或设计图纸库 |
| `scada_switchgear` | 开关开合遥信、保护健康、联锁许可、远方状态 | 监控与数据采集系统（SCADA） |
| `power_quality_meters` | 母线电压、有功、无功、分次谐波和总谐波畸变 | 电能质量表计 |
| `transformer_monitoring` | 环境温度、初始油温升、绕组热点温升和热参数 | 变压器在线监测系统 |
| `charging_management` | 充电枪安装数、可用数、车辆到达率、平均服务时长和实测队列 | 充电管理系统 |
| `battery_management_system` | 荷电状态、健康状态、温度、功率、吞吐、循环和质保边界 | 电池管理系统（BMS） |

每个域由数据所有者使用独立 Ed25519 私钥签名。服务端只配置公钥：

```bash
ELECTRICAL_SOURCE_PUBLIC_KEYS_JSON='{"site-sld-key":"...base64...","site-scada-key":"...base64..."}'
```

签名绑定该域的完整业务载荷；改变母线负荷、开关状态、谐波、温度、队列或质保参数都会使对应签名失效。现场签名工具：

```bash
backend/.venv/bin/python scripts/sign_electrical_source.py \
  --input site-electrical-request.json \
  --domain scada_switchgear \
  --private-key /secure/scada-ed25519.pem \
  --key-id site-scada-key \
  --output site-electrical-request.signed.json
```

私钥不得放入仓库、环境变量或驾驶舱主机。

## 3. 计算模型

### 3.1 拓扑和开关

支路必须引用两个已知母线和一个已知开关。闭合开关必须同时满足保护健康和联锁许可。基础运行方式必须是无环辐射网络，且所有标记为必须带电的母线均连接到公用电网或具备构网能力的可用电源。

联络开关可保持常开，并仅在指定 N-1 场景中按批准集合参与组合搜索。模型拒绝形成未批准环路的转供方案。

### 3.2 有功、无功和电压

模型对每个已带电辐射分量执行确定性前向—后向 LinDistFlow 工程近似：先从叶节点汇总下游有功和无功，再按支路标幺电阻、电抗与额定视在功率计算电压降和支路载荷率。

筛查同时验证：

- 所有必须带电母线的估计电压和现场实测电压均在批准带宽内；
- 线路和变压器视在功率不超过批准载荷率；
- 可用电源的有功、无功能力覆盖分量需求；
- 聚合功率因数不低于批准值。

该近似适用于运行筛查，不替代三相不平衡潮流、短路电流、保护配合或暂态稳定分析。

### 3.3 谐波

按各次电压谐波百分比计算：

```text
THD = sqrt(sum(harmonic_order_pct ^ 2))
```

当电表同时上报总谐波畸变时，门禁取“分次复算值”和“表计总值”中更严格者，不用较小值掩盖风险。

### 3.4 变压器热老化

模型使用负载率、负载损耗比、额定油温升、额定绕组热点温升、环境温度和一阶热时间常数，计算区间末油温升及热点温升。热点温度进一步换算老化加速因子：

```text
aging_acceleration = 2 ^ ((hot_spot_c - 110) / 6)
loss_of_life_hours = aging_acceleration * interval_hours
```

热点温度或老化加速因子超过经批准策略上限即阻断。公式和参数均显式版本化；现场必须用设备制造商资料、试验或资产管理批准值替换示例参数。

### 3.5 N-1 故障转供

每个场景指定一个故障支路和零个或多个批准联络开关。模型移除故障元件，并枚举最多三个批准联络开关的闭合组合。每个候选方案必须同时满足：

- 转供后仍为辐射网络；
- 开关保护健康且联锁许可；
- 关键负荷覆盖率不低于场景与全局策略中更严格的阈值；
- 电压、支路载荷、有功和无功能力全部合格。

报告保留每次尝试、所闭合联络开关、关键负荷覆盖率、电压和最大载荷率，不只返回一个布尔值。

### 3.6 孤岛运行

孤岛场景显式打开并网点开关，并排除公用电网作为电源。通过必须具备：

- 至少一个可用、构网且支持黑启动的非电网电源；
- 场景要求时长内足够的发电或储能可用能量；
- 储能保留最小孤岛备用能量；
- 关键负荷覆盖、电压、载荷、有功和无功能力全部合格。

报告只是可行性筛查，`islanding_command_allowed` 始终为 `false`。

### 3.7 充电排队

每个充电池按可用充电枪数量、车辆到达率和平均服务时间执行 Erlang-C M/M/c 排队计算，输出利用率、等待概率、期望等待时间和期望排队车辆数。当到达率不低于总服务率时，队列标记为不稳定并立即阻断。

现场需要定期用实际到达分布、服务时间分布和故障可用率复核 M/M/c 假设；存在显著预约、班次或优先级机制时，应升级到离散事件模型。

### 3.8 储能质保

按评估区间投影荷电状态、当日吞吐、累计吞吐和等效完整循环，并逐项检查：

- 充放电有功与无功能力；
- 荷电状态运行区间；
- 最低健康状态；
- 电芯最高温度；
- 每日吞吐和累计质保吞吐；
- 质保循环次数；
- 孤岛备用能量。

任一检查失败都会阻断储能质保门禁，不允许用经济收益覆盖设备安全或质保越界。

## 4. 十四项发布门禁

1. 六域具名数据覆盖
2. 逐源签名与防篡改
3. 时间新鲜度与跨源对齐
4. 单线拓扑引用完整性
5. 开关联锁与辐射运行
6. 母线电压约束
7. 馈线与变压器载荷
8. 无功与功率因数
9. 谐波畸变
10. 变压器热点与热老化
11. N-1 故障转供
12. 孤岛运行能力
13. 充电排队服务
14. 储能质保约束

状态机：

- `blocked`：六源覆盖、签名或时效未通过；
- `infeasible`：六源可信，但至少一个工程约束失败；
- `assessment_ready`：六源可信且全部工程筛查门禁通过，仍只允许人工复核。

公开数据默认报告为 `blocked`、`0/6` 源域、`0/14` 门禁，母线电压、谐波、热点、队列等现场指标均为 `null`。

## 5. 接口

- `GET /api/dashboard/electrical-network`：返回当前失败关闭准备状态。
- `POST /api/dashboard/electrical-network/evaluate`：评估完整签名现场包。
- `GET /api/dashboard/snapshot`：在统一驾驶舱快照的 `electrical_network` 字段返回相同报告。

驾驶舱“实时闭环”面板显示六源状态、14 项门禁和关键结果，同时固定展示生产控制禁用边界。

## 6. 实港验收清单

软件门禁通过之前：

1. 从获批单线图导入完整母线、支路、变压器、并网点和联络开关标识；
2. 对照现场逐项核验开关常态、CT/PT 变比、相序、额定容量与阻抗基值；
3. 统一 SCADA、电能质量表、变压器监测、充电管理和 BMS 时钟；
4. 为六个所有者分别发放、轮换和吊销 Ed25519 密钥；
5. 用现场潮流软件和实测电表对本模型结果做误差标定；
6. 注入开关遥信错误、失压、过载、高谐波、热点、通信中断和时间漂移；
7. 对每个 N-1 和孤岛方案取得电气负责人、调度、保护和安全部门批准；
8. 完成短路、继电保护、接地、弧闪、暂态、黑启动和反送电专项研究；
9. 在跨季节影子运行中对照实际告警、倒闸票、故障记录和设备寿命台账；
10. 只有独立生产指令网关、硬件联锁、双人审批、设备回执和现场回滚演练完成后，才可另行建设受控执行通道。

本仓库当前不包含第 8–10 项的现场授权和控制能力，因此不会将 `production_authority` 置为 `true`。
