# Asset provenance / 视觉资产来源

Three visual assets below were generated specifically for this repository
on 2026-07-21 with OpenAI's built-in image-generation workflow. They are
fictional presentation assets, not operational evidence or photographs of a
real terminal.

The generated PNG masters were converted to web-optimized JPEG derivatives
using macOS `sips`; no third-party photograph was used as an input reference.
The files intentionally contain no performance numbers, source claims, or
visible marks that could be mistaken for measured data.

The active interface uses only `xiaoyi-maritime-officer.png` for Xiaoyi. The
repository history does not contain a separate upstream license record for this
project-designated character asset, so redistributors should preserve this
notice and obtain any additional brand approval required for commercial use.

The interface screenshots are direct captures of the repository UI. Their
numeric values are deterministic benchmark outputs documented by the data and
model cards; they are not generated artwork and must not be presented as live
terminal measurements.
