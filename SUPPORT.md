# Support / 支持

## Questions and usage / 使用问题

Use GitHub Discussions for architecture, dataset-contract, experiment-design,
and integration questions after Discussions is enabled. Search existing issues
and documentation before opening a new thread.

仓库启用 Discussions 后，请使用它讨论架构、数据契约、实验设计和集成问题。提问前请先检索现有 issue 与文档。

## Bugs / 缺陷

Open a GitHub issue with the repository version, operating system, exact
command, minimal reproduction, expected behavior, actual behavior, and relevant
non-sensitive logs. Never attach credentials, private port data, or proprietary
model artifacts.

提交 issue 时请提供版本、操作系统、完整命令、最小复现、预期与实际行为及不含敏感信息的日志。请勿附加凭据、港口私有数据或专有模型产物。

## Security / 安全

Do not report vulnerabilities through public issues. Follow
[SECURITY.md](SECURITY.md).

安全问题不得通过公开 issue 报告，请遵循 [SECURITY.md](SECURITY.md)。

## Scope / 支持边界

Community support is best-effort. Maintainers do not provide production port
deployment approval, regulatory assurance, safety certification, or emergency
operational support. Production integration requires an independent engineering,
security, legal, and operational review.

社区支持为尽力而为，不提供生产港口部署批准、监管核证、安全认证或应急运营支持。生产接入必须经过独立的工程、安全、法律与运营审查。
